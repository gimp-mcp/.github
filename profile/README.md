## GIMP MCP

Home of [gimp-mcp](https://github.com/gimp-mcp/gimp-mcp), an open source [MCP](https://modelcontextprotocol.io) server that lets AI assistants (Claude, Codex, Gemini, and others) edit images in [GIMP](https://www.gimp.org).

- 56 GIMP tools: adjustments, transforms, selections, layers, drawing, text, filters
- Live visual feedback: the AI can see the image mid-workflow and verify each step
- Works with GIMP 3.2+

**Get started:** see the [README](https://github.com/gimp-mcp/gimp-mcp#readme).
**Contribute:** issues and pull requests are welcome.
